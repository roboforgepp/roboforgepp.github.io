# Pliki do pobrania

Tu trafiają modele STEP, dokumentacje PDF i inne pliki linkowane z podstron projektów.

W pliku projektu (`src/content/projects/*.md`) dodaj:

```yaml
downloads:
  - label: Model STEP podstawy kołowej
    href: /downloads/podstawa-kolowa.step
```

Ścieżka zawsze zaczyna się od `/downloads/` — katalog `public/` jest serwowany z korzenia strony.
